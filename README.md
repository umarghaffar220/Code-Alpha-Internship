 CodeAlpha C++ Internship Tasks

This repository contains the C++ tasks I completed as part of my **CodeAlpha Internship**.

The projects helped me practice C++ programming, problem-solving, functions, arrays, Object-Oriented Programming (OOP), recursion, and backtracking.

📌 Tasks

### 1. GPA & CGPA Calculator

A menu-driven C++ program that calculates a student's **GPA and CGPA**.

**Features:**
- Calculate GPA based on subjects, credit hours, and grades
- Calculate CGPA based on multiple semesters
- Convert letter grades into grade points
- Display results in a transcript-style format
- Display total credit hours and grade points
- Supports up to 10 semesters for CGPA calculation
- Menu-based navigation

**Concepts Used:**
- Functions
- Arrays
- Loops
- Conditional statements
- Strings
- Basic calculations
- iomanip` for formatted output

### 2. Banking System

A console-based **Banking System** developed using Object-Oriented Programming in C++.

**Features:**
- Customer information management
- Account information
- Deposit money
- Withdraw money
- Fund transfer between accounts
- Balance management
- Transaction history

**Classes Used:**

- `Transaction`

**Concepts Used:**
- Object-Oriented Programming (OOP)
- Classes and objects
- Constructors
- Encapsulation
- Functions
- Arrays
- Conditional statements
- Loops

3. Sudoku Solver

A C++ program that solves a **9×9 Sudoku puzzle** using the **backtracking algorithm**.

**Features:**
- Displays the original Sudoku puzzle
- Checks whether a number can safely be placed
- Checks rows, columns, and 3×3 subgrids
- Solves the puzzle using recursion and backtracking
- Displays the solved Sudoku
- Shows a message if no solution exists

**Concepts Used:**
- 2D Arrays
- Functions
- Recursion
- Backtracking
- Loops
- Conditional statements
